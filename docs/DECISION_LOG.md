# Decision Log

Chronological record of significant, non-obvious engineering decisions. Each entry: what was decided, why, and the alternative rejected. One line per decision; detailed context links where available. Format follows lightweight ADR practice; full ADRs live in `docs/adr/` when a decision warrants one.

| Date | Decision | Rationale | Rejected alternative |
| --- | --- | --- | --- |
| 2026-08-05 | Root `httputil` package stays flat (single package, ~35 files) | One import path beats fragmented namespaces for a middleware library where everything shares one signature; extraction is structurally impossible for compression (root-symbol cycle) | `internal/` split — deferred until root exceeds ~50 files (see `docs/modularization/2026-08-05_DECISION.html`) |
| 2026-08-05 | `Middleware` is a true type **alias** for `func(http.Handler) http.Handler` | External middlewares (e.g. `etag.New()`) compose directly with `Chain` without conversion shims | Type definition (would break bidirectional assignment) |
| 2026-08-07 | ETag extracted to the independent `go-etag` module; `httputil.ETag()` kept as a deprecated thin adapter | Conditional-request logic evolves independently; consumers pin their own version | Re-exporting go-etag domain types (rejected — adapter exists for composition, not API duplication; see `docs/adr/0001`) |
| 2026-08-07 | `ServerTimingMiddleware` lives in a stdlib-only sub-module | Embeddable in contexts that cannot take the root dependency set; zero transitive deps | Keeping it in the root module |
| 2026-08-08 | Validate-and-log, not validate-and-abort, for middleware constructors | Invalid config logs via `slog` and falls back to defaults; never breaks a running app at construction | Panicking / error-returning constructors (wrong ergonomics for middleware factories) |
| 2026-08-16 | `encoding/json/v2` for single-struct responses, with the trailing newline written explicitly | v2-native write path while keeping the documented 16-byte probe body stable; the 08-16 migration silently dropped the newline and was corrected 2026-08-29 (see `docs/reviews/2026-08-29_20-42_brutal-self-review.html`, finding F5) | Reverting to `encoding/json` v1 (downgrade shipped at v0.6.1 for flake reasons, superseded) |
| 2026-08-29 | Rate limiter keeps the admission-only contract through v1.0 (no ctx cancellation, no refunds) | One request in flight = one token; abort refunds create timing-dependent retry budget. `Wait(ctx, key)` remains a post-v1.0 additive path | Cancel-aware `Allow(ctx)` interface (see `docs/planning/2026-08-29_21-30_rate-limiter-ctx-cancellation-design-note.md`) |
| 2026-08-29 | D2 diagrams render only with the flake-pinned d2 (elk layout) | Different d2 versions produce different SVG layouts; pinning keeps historical diffs meaningful | Ad-hoc d2 installs |
| 2026-08-29 | No `MaxHeaderBytes` on ServerConfig; HSTS/HTTPS-redirect stay plugin-shaped ideas in ROADMAP | Go's 1 MiB header default is sane; HSTS/redirect policy belongs to deployers (proxy-trust semantics mirror ClientIP) | Adding fields speculatively |
| 2026-08-29 | TLS cipher suites: Go 1.26 defaults retained (no CipherSuites override) | Go's defaults track current best practice (TLS 1.3 suites + vetted 1.2 suites); overriding them creates a maintenance liability and freezes a moving target | Explicit CipherSuites allowlist in ServerConfig |
