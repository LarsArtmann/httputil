# Decision Log

Chronological record of significant, non-obvious engineering decisions. Each entry: what was decided, why, and the alternative rejected. One line per decision; detailed context links where available. Format follows lightweight ADR practice; full ADRs live in `docs/adr/` when a decision warrants one.

| 2026-08-30 | Hijack coverage restored as three tiers: interface test + light upgrade-response test + full byte-integrity test | The go-etag extraction and websocket-test removal had left Compression+ETag hijack behavior untested; splitting heavy (real TCP, bidirectional echo) from light (101 + header assertions) keeps the stable assertions in fast tests  | Single heavyweight real-TCP test (the fragile style removed 2026-08-07)                                                 |
| 2026-08-30 | Unknown-encoding tie-break uses a lexicographic rank, replacing the base-256 byte accumulation                   | The old accumulation overflowed `int` for names of nine or more bytes, making the documented deterministic order undefined for long names; a lexicographic rank is stable and overflow-free                                          | Keeping the accumulation (tie-break order among custom encodings only)                                                  |
| 2026-08-30 | `Recovery` re-panics `http.ErrAbortHandler` unchanged instead of recovering it                                   | The sentinel is stdlib's contract for silent mid-stream aborts; recovering it logged a full stack trace and wrote a doomed 500 to an already-aborted connection                                                                      | Treating it like any other panic (log + 500)                                                                            |

| 2026-08-30 | Reference decoders inside fuzz targets are always bounded (`io.LimitReader`)                                     | A fuzzed/corrupt input can otherwise make the reference decoder allocate until the runner dies; gosec G110 flags it, but the bound should not depend on lint being run                                                               | Unbounded reference decode                                                                                              |
