02Decision Gates (D1–D6)

D1 · Blocking

Home of negotiation

httputil ROADMAP §42 × go-appkit planning doc §Module sketch

httputil core middleware (Language(), zero-dep, KeyExtractor/Nonce precedents) vs a new appkit /i18n module vs integration-doc-only. The appkit doc already marks its own negotiation half SUPERSEDED-IN-WAITING. Recommendation: negotiation once in httputil; appkit keeps the content lane (Translator, MissingIn guards, Alternates, errorpages seam) and reads httputil’s context.

D2 · Blocking

Vary semantics

mirrors the open AbsentEncodingFirstConfigured lifecycle question

Always emit Vary: Accept-Language when chained (RFC-strict, CDN-safe even with URL/cookie extraction) vs only when the header leg can influence output (minimalist). Lean: RFC-strict default with opt-out.

D3 · Important

Matcher default vs dependency policy

httputil go.mod × x/text CLDR matching

Zero-dep primary-subtag default (policy-conformant; reproduces T49’s proven semantics but misroutes pt/zh script classes — conceded in ROADMAP §42) vs allowing golang.org/x/text for Matcher-grade CLDR correctness. The plugin escape hatch is the mitigation either way; discoverability of the escape hatch is the open risk.

D4 · Important

406 behavior + confidence exposure

config axes, not yet designed

Do q=0-only / no-match requests default silently, or does a RejectOnNoMatch axis exist (and in which error family)? Is the negotiated confidence (x/text-style) exposed in context or only the canonical tag?

D5 · Important

Cookbook canonical shape

go-appkit report Q3

German-canonical-unprefixed + /en (sperrmuell’s proven SEO shape) as the worked example, or also an EN-canonical global-SaaS shape? Affects defaults, example, docs depth. Lean: sperrmuell shape as worked example; the other as a config variant.

D6 · Important

Cross-repo authority

httputil report g3 × go-appkit report Q2

May a session write into sperrmuell-direct’s TODO_LIST and patch its /api/* headers (T03/T04)? Both sessions parked their most actionable consumer-side payoff on this ruling.
