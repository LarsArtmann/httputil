01What was fucked up

Lying diagram

The improved diagram drew a dependency that does not exist

old -improved.d2: compose → go-compression "WriterFactory plugin"

Compose knows nothing about compression's WriterFactory seam — Compression() owns it. A future go-compression module would PROVIDE factories to the existing seam, not receive edges from the composition API. A diagram that lies about dependencies is worse than no diagram.

Fixed Edge rewritten to the true direction: go-compression → root's Compression() middleware (dashed, trigger-gated), plus a second true edge (datastar importing compression standalone).
Inconsistent numbers

37 vs 38 non-test files across my own docs

boundaries.md, both .d2 files vs status report vs 08-30 refresh

Three different figures for the same count circulated in docs I wrote or maintained (36 pre-compose, then 37, then 38). The verified count: 37 non-test files in package httputil, 41 module-wide including httpspec.

Fixed Counted precisely with ls; corrected the new deliverables; the 08-30 doc is historical (annotated policy, not rewritten).
Unverified claims

"Known-evidence gap" was a choice, not a gap

boundaries.md v1: "whether any consumer imports httpspec is unknown"

Sourcegraph and pkg.go.dev imported-by pages answer this in one query. The answer materially changes the analysis: 4 consumer repos exist (all owner-owned), cqrs-htmx imports server_timing standalone (proving that module's composability payoff), and httpspec has zero importers anywhere (killing the module-split question for good and exposing a discovery gap instead).

Fixed Scan executed; boundaries.md now carries the importer table and the resolved-gap section. The verdict holds but is now evidence-based instead of assumption-based.
Diagram syntax drift

Used an unverified D2 style key; skipped the syntax reference

-improved.d2: style.border-dashed (invalid on this d2 build)

The skill says every snippet in its reference renders on the local d2 — but my first rewrite didn't re-check it, quoted neither labels with ;/: nor used the working dash key. ELK rejected the file twice before it rendered. Following the cheat sheet from the start would have been zero failures.
