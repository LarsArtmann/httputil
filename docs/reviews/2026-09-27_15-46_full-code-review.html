01Fixed on the spot (verified by gates)

Minor · code

Metrics() skipped the validate-and-log contract; nil Recorder panicked at request time

metrics.go:54 (before fix)

Every other middleware constructor calls validateConfig(...) at construction; Metrics() was the lone exception (verified via git history — never present, an original omission, not a deliberate removal). A nil-Recorder config constructed silently and nil-panicked on the first request, contradicting the never-panics-by-design owner directive.

Fix Constructor now logs the misconfiguration and the middleware serves without recording (the documented fallback for configs without defaults). Pinned by TestMetrics_NilRecorderServesWithoutRecording; Metrics at 100% coverage.
Minor · tests

Zero-value MiddlewareStack path unexercised — a coverage regression nobody would have noticed

stack.go:76 snapshot() — 66.7% before fix

The re-measurement for this review surfaced a sub-100% function absent from the FEATURES.md gap registry: snapshot()'s never-stored branch. The zero value works by design (Load→nil, CAS nil→next), but nothing pinned it — a future refactor could silently break var s MiddlewareStack usability.

Fix TestMiddlewareStackZeroValueUsable pins Add/Build/Names/Validate on a zero-value stack; snapshot() now 100%.
Docs · pkg.go.dev

Package doc still advertised the removed ETag adapter

doc.go:7-8 (before fix)

"ETag conditional requests via the go-etag adapter" — the adapter was removed in v1.1.0; the dependency remained only for error-code registration. Consumers browsing pkg.go.dev were promised a capability that does not exist.

Fix Reworded to the accurate contract: RegisterErrorClassifications registers the go-etag error-code superset; conditional requests live in the separate go-etag module.

03Patterns to preserve

+
The v1.4.0 delta is exemplary middleware engineering. csrf.go's SameSite fallback is a pure helper with logging at the constructor, mirrored in InvalidateCSRFCookie, opt-out flag, and an honest known-limitation note on the nosurf pattern-propagation boundary; the TrustedOrigins all-or-nothing parse mirrors nosurf exactly so attestation can never trust a different set than enforcement. ServeMux pattern propagation landed in all five fixable fork sites with identical comments; CSRF's impossibility is documented instead of hand-waved.
+
Error taxonomy discipline held through growth. Every new code in the delta (csrf.trusted_origin_invalid, compression.absent_encoding_invalid) shipped with sentinel, template entry, context keys, docs sweep, and correct family — the completeness test plus the review checklist make drift structurally hard.
+
Zero-overhead opt-outs and nil-safety are consistent library-wide. AbsentEncodingPolicy's zero value is the safe one (identity); the nonce and Server-Timing collectors are nil-receiver no-ops; ServerTimingMiddlewareWhen passthrough wraps nothing. Defaults protect the careless caller without punishing the deliberate one.
+
Documentation is load-bearing, not decorative. AGENTS.md constraints predicted every lint trap this session could have hit; FEATURES.md's every-gap-needs-a-reason rule is what made the stale registry and the stack.go hole visible at all. The doc-snippet-refs script turns doc drift into a build failure.
