Patterns to preserve

ID generator race-freedom by construction. Claim-then-load over immutable published generations: no locks on the hot path, abandoned slots never reused, superseded buffers GC-reachable through slow readers. The doc records why the old shared buffer was wrong.
Written trust boundaries. contradictedAttestationOrigin is a pure function with an argued trust model, now extended with proxy-scoped X-Forwarded-Proto that grants trust only where TrustedProxies already does.
Enforced error-taxonomy completeness. Template table coverage asserted by errors_templates_test.go — adding a code without a template fails the build, not a review.
Tiered fuzz oracles. Universal weak invariant + strong invariant gated on provable preconditions (CORS origin echo), dual-channel status+body oracles (CSRF), decode-and-compare round-trips with bounded decoders (compression) — the strengthened CSRF oracle caught its own stale prediction model the day the trust model changed.
