TODO_LIST.md rebuilt 2026-08-29 from the 20 open-item appendix lines: deduped, routed (TODO/ROADMAP/Won't), every item carrying report citations and the plan-task mapping.

F3 — Environment blocker silently ate the quality gate

/mnt/buildcache is unwritable here, so go test, go vet, and golangci-lint all failed at cache init — looking like infra breakage rather than a fixable env problem. The prior session documented the blocker but did not solve it.

Fixed: cache overrides documented

GOCACHE, GOLANGCI_LINT_CACHE, and GOMODCACHE overrides unblock all three tools; the export block is now in AGENTS.md Commands. Lint gate re-verified: 0 issues.

F5 — The test suite has been red since 2026-08-16 and nobody ran it

Commit d466d2d ("style: reformat … No behavior changes") swapped json.Encoder.Encode for json.MarshalWrite in health.go. Encode appends a trailing newline; MarshalWrite does not. Six health-endpoint tests failed from that day on — but every session's go test died at the /mnt/buildcache cache-init error first, so the red suite stayed invisible for 13 days. A style commit broke the documented 16-byte probe contract.

Fixed: contract restored, suite green

health.go now writes the payload via MarshalWrite plus an explicit newline through one writeHealthBody helper (the v2 migration stays; the documented 16-byte body returns). go test -race ./... green; golangci-lint run: 0 issues. The exact-byte test now guards a truthful contract again.

F4 — AGENTS.md prose drift

"34 non-test files" was stale — the tree has 35. Table rows were complete; the prose count was not. Small, but AGENTS.md is the file every session trusts first.
